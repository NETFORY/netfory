# AI Demo пример dApp с useAI

Готовый пример приложения для каталога NETFORY: стриминговая генерация
текста на децентрализованном AI-суперкомпьютере через
`window.smartholdem.useAI()`.

## Что показывает

- проверку доступности AI-сети (`window.__SMARTNET__.features.ai`)
- стриминг токенов в реальном времени (`onToken`)
- финальный результат (`await job.done` -> `{ text, node, ms }`)
- отмену генерации (`job.cancel()`)
- выбор модели и лимита токенов

## Как опубликовать в каталог

1. Откройте NETFORY -> каталог приложений -> «Опубликовать dApp».
2. Выберите папку `dapps/ai-demo` (в корне обязателен `index.html` он тут).
3. Подпишите публикацию своим ключом приложение появится в каталоге,
   и любой пользователь сможет открыть его по `sth://`-ссылке.

Для работы AI нужен хотя бы один активный AI-воркер в сети
(`netfory-ai-worker start …`) иначе диспетчер вернёт
«в сети нет подходящих AI-нод».
